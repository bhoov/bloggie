# How This Blog Works

Interactive essays, talk decks, and an agent that keeps them in step

<Notes>Every slide here is written in the same plain text as the post; the post shows this deck's source.</Notes>

## Two Commands to Start

```sh
npx github:bhoov/bloggie my-blog
cd my-blog && npm run dev
```

<Notes>A static site built with Astro: no server, no database, no account. It redraws on every save. Add --title, --author and --url to the first command to name the blog, or set them later in src/site.js. Copy this post's folder to start your own.</Notes>

## Everything Is Plain Text

- **index.mdx** the post
- **slides.mdx** its deck
- **data/** and **media/** what it shows

<Notes>The folder is src/pages/posts/ and a slug. Copy this post's folder to start a new post; rename it to _how-this-blog-works to take the example off the site. One sentence per line, so a diff shows which sentence changed.</Notes>

## [equation eqSize=54] Equations Explain Themselves

$$
\state{Y} = \underbrace{\operatorname{softmax}\!\left(\frac{\given{X}\coupling{W_Q}\,(\given{X}\coupling{W_K})^\top}{\sqrt{d}}\right)}_{\mathclap{\note{attention weights}}}\;\underbrace{\given{X}\coupling{W_V}}_{\note{values}}
$$

- $\given{X} \in \mathbb{R}^{N \times D}$ the tokens
- $\coupling{W_Q}, \coupling{W_K}, \coupling{W_V}$ the projections
- $\state{Y} \in \mathbb{R}^{N \times d}$ the output
- Each output row is **a weighted average of values**

<Notes>Typeset when the site builds, numbered and linked as in Quarto. Braces name the terms; the legend names the symbols.</Notes>

## Citations Number Themselves

```mdx
<Cite key="vaswani2017">[1]</Cite>
```

Add a source once to **references.json**; the post numbers it and lists it at the end.

<Notes>The number follows the order of first use, the source shows on hover or tap, and the build fails on a key that is not in src/references.json.</Notes>

## An Agent Writes the Deck

Ask for **slides for this post** with the bloggie-slides skill, which ships with the blog.

<Notes>It lives in .agents/skills/bloggie-slides/, so any coding agent can read it. It makes one idea per slide, text for the back of the room and full-slide demos, checks every slide in a browser, and then says where the post's story was hard to follow.</Notes>

## [reasons] Fine-Tune It With the Mouse

- **Press E** on a deck, under npm run dev
- **Drag, resize, align** blocks, and edit text in place
- **Every change** is written to the deck's text file

<Notes>Show it live: press E, drag a paragraph, double-click a word and color it. The keys follow Figma's. Because the deck stays a text file, your edits and an agent's mix freely.</Notes>

## Keep Post and Deck in Step

Change the post, then ask the agent to **update the deck**. Your layout stays.

## One Style, Written Down

- **AGENTS.md** is the style guide every agent reads
- One sentence per line, an example beside each idea
- Add your own rules in plain English

<Notes>Claude Code and Codex both read AGENTS.md. The build enforces the mechanical rules: a broken link or an unknown citation stops npm run build.</Notes>

## Leave Notes for the Agent

Write **&#40;&#40;shorten this&#41;&#41;** anywhere in a file, and the agent does it and removes the note.

<Notes>In the text or in a comment. It says what it did for each note, and leaves ((IGNORE …)) alone.</Notes>

## [reasons] Download for Offline Distribution

- **Interactive page** one HTML file that works offline, deck inside
- **For agents** text, math as TeX, figures described, source code

<Notes>The download icon in the byline, and the menu beside it. Present from a laptop without a network, or hand the post to another agent as reading material.</Notes>
